## 项目配置
可以在根目录的`.vscode/settings.json`设置
```jsonc
{
    "java.project.referencedLibraries": [
        "D:/Java/.minecraft/libraries/org/ow2/asm/asm/9.10.1/asm-9.10.1.jar",
        "D:/Java/.minecraft/libraries/org/ow2/asm/asm-analysis/9.10.1/asm-analysis-9.10.1.jar",
        // 其它各种来自于 -cp 的依赖库，以半角分号分割
        "libs/*"
    ],
    "java.project.sourcePaths": [
        "src/main/java"
    ],
}
```
这样Microsoft VSCode就可以在缺少Gradle的情况下正确显示Java语法高亮与代码补全了。
